# SalesSavvy

SalesSavvy is an e-commerce application being developed as a course project for small and medium-sized businesses.

## Tech Stack

* Java
* Spring Boot
* Spring Security
* Spring Data JPA / Hibernate
* MySQL
* REST APIs
* JWT Authentication
* BCrypt
* Git / GitHub

## Current Features

* User registration and login with BCrypt password hashing and JWT authentication
* Role-based authorization using Spring Security
* Product and Category CRUD operations
* Product-Category JPA relationship
* Product search and category-based filtering
* Pagination for product listings
* Custom exception handling
